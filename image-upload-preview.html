✨ Key Features

📁 File Types

Supports JPEG, PNG, GIF, and WebP formats

📏 Size Limit

Maximum 5MB per image with automatic validation

👁️ Preview

See your image before uploading to confirm

💾 Storage

Base64 encoding stored directly in SQLite

📱 Responsive

Works perfectly on mobile and desktop

🗑️ Easy Delete

Remove images with a single click

📖 How to Use

Simple 5-step process to upload event images:

1. Navigate to Insights section
2. Select an event from the dropdown
3. Click "📷 Upload Image" button
4. Choose your image file (max 5MB)
5. Preview and click "Upload Image"
🎯 Best Practices
  • Use high-quality images (1200x800px recommended)
  • Compress images to under 500KB for faster loading
  • Use 16:9 aspect ratio for best display
  • Professional images enhance event credibility
